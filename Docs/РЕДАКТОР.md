# Инструкция пользователя: Редактор полос (Fringes Editor)

## Режимы работы

Редактор полос имеет два режима: **Edit** (редактирование) и **Navigate** (просмотр и выделение).

---

## Режим Edit (Редактирование)

**Включение:** Меню → "Numbering" → "Add Dot" или кнопка "+." на панели инструментов

### Рисование и редактирование полос:

#### Активация полосы и точки:
- **ЛКМ на конец полосы** → выбрать активную точку

#### Создание полос:
- **ЛКМ на пустой области при НЕ активной полосе** → начать новую полосу с номером CurrentNumber+step
- **ЛКМ на пустой области при активной полосе** → добавить точку к концу активной полосы

#### Перетасккивание точек и отрезков
- **ЛКМ на точке/отрезке, тащить → переместить точку/отрезок

#### Соединение полос:
- **Ctrl+ЛКМ на конец другой полосы** → соединить активную полосу с другой полосой (конец к концу)

#### Вставка точки:
- **Ctrl+ЛКМ на отрезок (edge)** → вставить точку в середину отрезка

#### Завершение полосы:
- **Ctrl+ЛКМ на пустой области** → завершить текущую полосу без добавления точки
- **Enter** → завершить текущую полосу

#### Удаление:
- **Backspace** → удалить последнюю точку активной полосы
- **Escape** → отменить рисование текущей полосы (деактиввация точки, режим Edit остаётся активным)
- **Alt+ЛКМ на точку** → удалить точку
- **Alt+ЛКМ на отрезок (edge)** → удалить отрезок = разбить полосу на 2 части

### Управление номерами полос:

- Поле ввода / кнопки "+"/"-" на панели инструментов → переключение текущего номера (CurrentNumber)
- Новая полоса будет создана с номером на 1 шаг выше текущего (numStep = 1.0)
- Кнопка "Delete Fringe" меню → удалить все полосы с текущим номером

---

## Режим Navigate (Просмотр и выделение)

**Включение:** Выключить режим Edit (меню → "Add Dot" ещё раз, или выбрать другую команду редактирования)

### Выделение полос:

#### Выделение прямоугольником (Box Select):
- **ЛКМ на пустой области + перетаскивание** → выделить все полосы и отрезки в прямоугольнике:
  - Выделяются: точки внутри, отрезки пересекающие границы, или целые полосы (если ВСЕ отрезки внутри)
  
- **Shift + перетаскивание** → выделить целые полосы, если ЛЮБАЯ часть пересекает прямоугольник

- **Alt + перетаскивание** → выделить ВСЕ полосы с одинаковым номером, если хотя бы одна пересекает прямоугольник

- **Ctrl + перетаскивание** → добавить к существующему выделению (вместо замены)

#### Выделение кликом:
- **ЛКМ на точку/отрезок/полосу** → выделить один объект
- **Ctrl+ЛКМ** → добавить к выделению или убрать из выделения (toggle)
- **Shift+ЛКМ** → выделить диапазон точек (будущая функция)
- **Alt+ЛКМ** → выделить ВСЕ полосы с одинаковым номером (promote to Fringe)

### Визуализация:
- Выделенные точки/отрезки подсвечиваются жёлто-золотистым цветом (glow effect)
- Для отрезков: выделяются сами отрезки, а не точки (для наглядности)
- Для одиночных точек в полосе: подсвечивается сама точка и соседние отрезки

### Навигация:
- **Ctrl+Z / Ctrl+Y** → отменить/повторить последнее действие (во всех режимах)
- **Scroll / Ctrl+колесо** → масштабирование

## Быстрые горячие клавиши

| Действие | Горячая клавиша | Режим |
|----------|-----------------|-------|
| Отменить | Ctrl+Z | Оба |
| Повторить | Ctrl+Y | Оба |
| Завершить полосу | Enter | Edit |
| Завершить (Ctrl) | Ctrl+ЛКМ | Edit |
| Удалить последнюю точку | Backspace | Edit |
| Соединить полосы | Ctrl+ЛКМ на точку | Edit |
| Вставить точку в отрезок | Ctrl+ЛКМ на отрезок | Edit |
| Отменить рисование | Escape | Edit |
| Перейти в соседнюю полосу | Tab/Shift+Tab | Edit |
| Выделить диапазон | Shift+ЛКМ | Navigate |
| Добавить к выделению | Ctrl+ЛКМ | Navigate |
| Выделить все полосы (Fringe) | Alt+ЛКМ | Navigate |
| Выделить целые полосы | Shift+перетаскивание | Navigate |
| Выделить полосы (Fringe mode) | Alt+перетаскивание | Navigate |
| Добавить к выделению (box) | Ctrl+перетаскивание | Navigate |

## Примеры работ

### Оцифровка новой полосы:
1. Включить режим Edit (меню → Add Dot)
2. Установить номер полосы (поле ввода или кнопки +/-)
3. Кликнуть ЛКМ на изображении → начать рисовать
4. Добавлять точки ЛКМ по полосе
5. Если нужно соединить с другой полосой: Ctrl+ЛКМ на её конец
6. Enter или Ctrl+ЛКМ на пусто → завершить полосу

### Проверка и редактирование оцифрованных полос:
1. Выключить режим Edit → включится режим Navigate
2. Выделить полосы прямоугольником (перетаскивание)
3. Просмотреть выделение (золотистая подсветка)
4. Ctrl+Z для отмены ошибок

### Удаление полосы:
1. Режим Edit: Install номер полосы, затем меню → Delete Fringe
2. Или режим Navigate: выделить полосу (Alt+ЛКМ), затем меню → Delete Fringe

---

## Рекомендации

- Используйте **режим Navigate** для просмотра и проверки оцифровки
- Используйте **режим Edit** только при добавлении новых или редактировании существующих полос
- Часто сохраняйте работу (Ctrl+S)
- Используйте Ctrl+Z если сделали ошибку
- Для быстрого удаления последней точки: Backspace (не нужно переключать режимы)

---

## Клавиши навигации (режим Edit)

При работе с массивом точек (Dots):
- **Левая/Правая стрелка (←/→)**: перемещение по точкам в текущей горизонтальной строке (ZapSection)
- **Вверх/Вниз стрелка (↑/↓)**: перемещение между полосами (по номерам) в одной позиции X

Это позволяет быстро навигировать по оцифрованным данным без использования мыши.
