## ?? Key Lessons

### Understanding the Data Structures

#### **Source Arrays** (Input from User)
```cpp
pB->ArrEll   // Original ellipses
pB->ArrRect  // Original rectangles
pB->ArrPlg   // Original polygons
```
- **When**: Set when user draws shapes
- **Purpose**: Store user input
- **Problem**: Mixed types, not processed

#### **Computed Contours** (Output from CalcContour)
```cpp
pB->ArrContour  // Processed polygon contours
```
- **When**: Generated by `CalcContour(ArrEll, ArrRect, ArrPlg, ...)`
- **Purpose**: Unified, processed boundary representation
- **Advantages**: ? All shapes ? polygons, ? Visibility computed, ? Closed contours

### The Data Flow

```
User Draws:
  Ellipse ? ArrEll[0]
  Polygon ? ArrPlg[0]
         ?
  CalcContour()
         ?
  ArrContour[0] = Polygon (from ellipse, 500 points)
  ArrContour[1] = Polygon (from polygon, 300 points)
         ?
  CreateRedCenters() ? Should use ArrContour!
```
