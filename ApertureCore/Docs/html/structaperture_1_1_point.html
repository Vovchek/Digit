Detailed Description

2D point in Cartesian coordinates

A lightweight struct representing a point in 2D space. Uses double precision for compatibility with scientific computing and legacy code.

The Point struct is designed as an aggregate type, allowing brace initialization and guaranteed copy elision. All methods are constexpr where possible for compile-time evaluation.

Memory Layout

Point p{x, y};
sizeof(Point) == 16 bytes (2 × sizeof(double))
