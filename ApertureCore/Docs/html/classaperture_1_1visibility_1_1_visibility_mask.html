Detailed Description

Pure data container for pixel visibility.

Stores per-pixel visibility for a bitmap with version metadata for cache validation. Uses flat storage for efficiency.

Rules:

  • No geometry logic
  • No rebuild logic
  • No threading
  • No dependency on UI or documents
