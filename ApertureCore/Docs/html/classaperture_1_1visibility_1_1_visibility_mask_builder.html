Detailed Description

Stateless builder for VisibilityMask.

Heavy CPU operation that iterates all pixels and queries VisibilityChecker to build a fresh mask.

Constraints:

  • Stateless (all static)
  • No caching
  • No ownership of shapes
  • No global state
  • This is the ONLY place with per-pixel loops
